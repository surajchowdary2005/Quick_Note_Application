# 📝 Quick Note Application

A simple and responsive full-stack **Quick Note Application** built using **Node.js, Express.js, HTML, CSS, and JavaScript**.

## 🚀 Features

* ➕ Add new notes
* 📋 View all notes
* 🗑️ Delete notes
* ⚡ REST API using Express.js
* 🔄 Asynchronous API requests using `fetch()`
* 💾 Notes stored in a local JSON file
* 📱 Responsive design
* 🎨 Clean and simple user interface

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express.js
* **Data Storage:** JSON
* **API:** REST API
* **Version Control:** Git & GitHub

## 🔗 API Endpoints

| Method | Endpoint     | Description       |
| ------ | ------------ | ----------------- |
| GET    | `/notes`     | Get all notes     |
| POST   | `/notes`     | Create a new note |
| DELETE | `/notes/:id` | Delete a note     |

## ▶️ How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/surajchowdary2005/Quick_Note_Application.git
```

### 2. Open the project folder

```bash
cd Quick_Note_Application
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the application

```bash
npm start
```

### 5. Open in browser

```text
http://localhost:3000
```
